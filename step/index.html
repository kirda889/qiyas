شروحات القواعد

ملخص شامل لكل القواعد — اقرأها أولاً ثم انتقل للأسئلة

TENSES

ملخص الأزمنة الستة

Present Simple
العادات والحقائق: S + V1
⚠ always, usually, every day
Present Continuous
حدث الآن: S + am/is/are + V-ing
⚠ now, right now, look!
Present Perfect
ربط الماضي بالحاضر: S + have/has + V3
⚠ already, yet, since, for
Past Simple
حدث انتهى: S + V2
⚠ yesterday, ago, last week
Past Perfect
الحدث الأقدم: S + had + V3
⚠ by the time, before, after
Future
will + V1 | will be + V-ing | will have + V3
⚠ tomorrow, by + مستقبل
CONDITIONALS

ملخص الشرطيات

Zero Conditional
حقائق ثابتة
If + Present → Present
If you heat ice, it melts.
First Conditional
ممكن بالمستقبل
If + Present → will + V1
If I study, I will pass.
Second Conditional
خيال بالحاضر
If + Past → would + V1
If I were you, I would go.
Third Conditional
ندم بالماضي
If + had V3 → would have V3
If I had studied, I would have passed.
⚠ لا تستخدم will بعد if! | في الثانية نستخدم were مع كل الضمائر
PASSIVE & MODAL

المبني للمجهول + أفعال Modal

Passive Voice
Object + be + V3
Present: is/are + V3
Past: was/were + V3
Perfect: has/have been + V3
Future: will be + V3
Modal Verbs
must = ضرورة | should = نصيحة
can = قدرة | might = احتمال

Modal + have + V3 (ماضي):
should have = كان لازم (ندم)
must have = أكيد (استنتاج)
can't have = مستحيل
CONNECTORS

أدوات الربط الأساسية

التضاد
although + جملة
despite + اسم
however (بعد ;)
but / yet
السبب
because + جملة
due to + اسم
since + جملة
because of + اسم
النتيجة
therefore
consequently
so
thus / hence
⚠ because + جملة | due to + اسم — لا تخلط بينهم! | So = Therefore | But = However

READING STRATEGY

استراتيجيات القراءة الذهبية

اقرأ الأسئلة أول ثم القطعة — يوفر وقت كثير!
حدد الكلمات المفتاحية في السؤال وابحث عنها في النص
لا تختر إجابة لمجرد أنها تذكر كلمة من النص — ممكن فخ!
في Main Idea: لا تختر تفصيل واحد بل الفكرة الشاملة
في Vocabulary: المعنى يعتمد على السياق وليس المعجم
في Inference: الجواب ما يكون مذكور مباشرة — استنتج!
⚠ وزّع الوقت: 1.5 دقيقة لكل سؤال | المواضيع المتكررة: البيئة، التكنولوجيا، الصحة، التعليم

قسم الاستماع

Listening — 20% — المقطع يُشغّل مرة واحدة فقط!

LISTENING TIPS

نصائح الاستماع الذهبية

اقرأ الأسئلة قبل ما يبدأ المقطع — أهم نصيحة!
المقطع يُشغّل مرة واحدة فقط — ركّز من أول لحظة
الكلمات الانتقالية (however, but, actually) — الجواب غالباً يجي بعدها
لو سمعت كلمة من الخيارات بالضبط — غالباً فخ!
انتبه لنبرة المتحدث: متحمس؟ قلق؟ ساخر؟ محايد؟
تدرب يومياً: BBC Learning English / TED Talks
